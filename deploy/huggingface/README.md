# Algo Trade Simulator

Live demo of [github.com/varun-sharma-2006/AlgoTrade](https://github.com/varun-sharma-2006/AlgoTrade).
Backtest SMA crossover, mean reversion and breakout strategies on real market data, fees included and compared
with buy & hold, plus live charts and a trading copilot.

The demo stores data in memory, so it resets when the Space restarts. Educational use only, not financial advice.
